Chat and circles
Lists are edge-to-edge rows with hairline structure instead of stacks of shadowed cards. The thread slides over the list like iMessage, and you can drag it back from the left edge with the list visible underneath.
Messages. Large left title, one search field, unread shown by weight and an accent dot. Circle chats get rounded-square avatars so they read differently from people.
Thread, mid swipe-back. The chat list stays mounted underneath and shifts in as you drag. No reload, no blank frame, no scroll animation on open.
Circle. The cover photo does the visual work. Black primary button, simple underline tabs, events as plain rows with a date block. Chat opens the same thread screen as DMs.
